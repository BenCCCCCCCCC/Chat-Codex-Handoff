## B 批的领域合同

- 目标引用材料选段或当时的学习重点。旧主题可以只有自由文本目标。
- 一条可定位的诊断保留来源版本、讲解 ID、确认文字版本、报告 ID 和发现索引。缺少唯一历史关联时只显示已有记录。
- 重讲与练习用现有 parent / feedbackRef / origin 关联；修改文字、答题草稿、已提交回答及当前有效反馈分别展示。条件不明或题目复核时暂停判断。
- 理解档案从上述事件派生，随主题到期。下一批将把同一点的初讲、重讲和练习放在同一视图，并增加从补学回到该点重讲的入口。
