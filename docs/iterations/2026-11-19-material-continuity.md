# 材料续学与日常恢复

依据 MASTER `190f83e`、产品审查 `docs/master/reviews/2026-11-19-product-review.md` 和 Issue #39；产品基线 `7fddda1`，工作分支 `codex/material-continuity-39`。本批包含当前材料续学阶段，以及相邻的录音恢复／到期提示；最终提交、PR 和 CI 回执见 Issue #39 与 MASTER。

## 已解决

- 在 A 学习时引用 B 保存的条件不再因旧组合 ID 静默消失。条件按实际引用材料判断是否可采用；缺 B 时显示名称和“补入依据并继续讲解”。原有受影响记录直接可用，无需重抄。相同引文恰好出现在 A 中也不能冒充已经采用 B。
- “补充并接着学”及“用所选材料接着学”承接当前表达（包括已保存的未确认编辑）、问题、有效目标和对话要点。新依据下建立明确标识的承接文字，先保存、再修改确认、最后明确分析；不会携带旧回答判语去影响新反馈。用户仍可只存材料或打开材料下的已有工作。
- 旧讲解／条件／反馈保留原来源和版本，新旧表达与各自反馈可并列查看。返回原讲解及精确来源仍可用；目标位置已有草稿、问题或未知请求不会被覆盖。承接文字不标成新的独立作答。
- 原有条件练习继续接收新反馈的固定条件。保存、搜索、材料历史及导入恢复保持关联。含续学或录音片段范围的记录导出 v4，旧应用拒绝未知格式，避免忽略片段范围继续判遗漏；本版继续读取 v1/v2/v3。不改数据库结构、保留期或发送上限。
- 学习页和历史卡片直接显示实际到期时间和不自动续期的说明，保留就近导出入口。
- 无 AI 录音保留为本机已保存状态，不冒充未知转写失败。录音中断后原声不丢失，提供文字续接或明确转写已保留片段；原中断标记始终保存。片段内容只分析已经录下的部分，结构校验拒绝 `missing`，不将未录内容计为遗漏。补材料承接这种文字时也保留片段范围。
