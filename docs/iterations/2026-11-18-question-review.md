# 题目质疑后的核对、修订与再次作答

学生标记“题目有疑问”后可记录疑点、查看原材料、引用依据并填写完整修订题，刷新后继续。材料外的引句不能确认；疑问可以先保存并保持暂停。按材料自查后可保留原题重新作答，也可预览并确认另建修订题。预览支持取消和键盘退出；重复确认或保存失败后的重试不会另建重复题。

修订保留原题、原情境、原回答草稿、所有回答和先前反馈。原题只读，可往返修订题，连续修订有完整来源链；从原反馈再进入会打开最新修订。核对及撤回留下记录，可搜索到对应说明。修订、复核记录随主题备份恢复，无数据库升级。

题目待核对时暂停判断。核对前的判断保留为历史，不作为答错依据，不再被重复回答缓存复用，也不传入后续 AI 判断；撤回下一次质疑不会恢复此前已排除的判断。保留原题后提交相同回答也会形成新的判断。修订本机规则题不会沿用旧答案键，而是进入明确提交才调用既有 API 的开放回答流程。

复核目前是学生按材料自查：存在原文引句不证明题目语义正确，界面明确标注尚非独立复核。本轮没有自动判定题目有效、引入教师复核或证明学习效果。本机任务原有的来源与答案键完整性校验继续保留，损坏任务不能借质疑标记绕过备份导入校验。
