# 已有音频上传与分离质量评估

跟踪：[Issue #14](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/issues/14)。最终合并、CI 与接续状态写入 `meta/master-state`。

## 产品变化

- “我来讲讲”中加入“上传音频”，与录音共用后续核对、诊断、失败恢复、搜索和导出流程。
- 选择文件后只在本机解码、检查并保存原始字节，可以先试听。用户点击“开始转写”才发送音频；刷新不会触发调用。保存失败复用现有内存恢复和导出提示。
- 接受 WAV、MP3、M4A、MP4、WebM、OGG、FLAC、AAC 扩展名，实际可读性取决于浏览器解码支持。每次最长 3 分钟、文件最大 25 MiB，不静默截断。不能解码／超长时不创建尝试，不调用 API。
- 统一通过单声道 16 kHz 归一化后检查和转写，修复只检查第一个声道而误判右声道声音为静音的问题。归一化音频只作临时缓存，保存／导出仍为原始音频字节。
- 上传来源保存 `captureOrigin`、文件名，辅助条件为 `unknown`，不推断用户当时脱稿。兼容现有 v1 备份，无数据库迁移。
- 未转写时只展示试听与转写操作，隐藏空白核对标题、原始转写、内容反馈和过程区域。文件名与录音细节仍折叠显示。

## 分开衡量质量

`quality-eval.mjs` 分开计算字符差异、时间字段有效性、内容 verdict 和引用／版本有效性。没有把编辑次数当识别准确率，也没有将桩 API 的流程通过率视为模型质量。

`quality-history.mjs` 不导入 provider、不联网，可复算历史公开响应，输出 [历史基线 JSON](../research/voice-quality-baseline.json)。历史结论：

- 7.31 秒合成音频：24 字中严格 CER 为 9/24 = 37.5%，九处都是简繁写法差异；“只有、才、不要”保留。不能解释为 37.5% 的语义识别错误。一个词的时间为零长度，词级定位仍部分不可用。
- 首轮内容 6/7 verdict 符合固定预期，自我修正被多判一条错误；当轮引文／结构校验均通过，说明引用有效不等于判断正确。
- 第二轮原记录因 `CHANNEL_LEAK` 停止，缺少完整 fixture／expectation，不重新推断成通过。
- 后续修订 7/7 verdict 与引用检查通过，但自我修正的一条建议只有“. .”。其余理由保留条件方向、明确缺失不代表永久不会，未观察到来源外断言；这个小样本不能支持总体准确率或稳定性结论。

历史提示与校验有修改，因此以上不是同条件模型 A/B，也不是当前模型成绩。没有改写 Phase 3B 的两份历史报告或它们未知的请求归因。

## 本轮真实实验

用户已明确批准[固定方案](../research/2026-10-20-voice-quality-plan.md)：一条既有合成音频转写、七条固定文字分析及一次自我修正重复，最多九次，硬上限 US$0.10。预留上界 US$0.08328，不自动重试、不充值。

运行器 `quality-live.mjs` 复用当前 provider 和全局账本，叠加九次／$0.10 上限；逐次写入响应、请求标识、评分和用量；已有报告拒绝覆盖。第一次本地预检发现旧 System.Speech 文件使用 18 字节 fmt 头，在网络发送前停止（0 请求、0 费用）。保存停止记录后修正为标准容器，PCM 字节未变，再执行原批准方案。

[本轮完整合成输入、响应、评分与人工复核](../research/voice-quality-live.json)已保存：

- 9 次调用全部完成，累计保守预留 US$0.0455655；实际账本新增估算 **US$0.004224**，新增未结算 0。不使用剩余预算自动扩大实验。
- Whisper：严格 CER 9/24 = 37.5%，九处仍全为简繁差异，否定词和条件方向保留；22 个词中 `w14` 时间长度为零。单段转写有效，词级时间部分可用，未声称人工时间对齐准确率。
- 内容：8/8 固定 verdict 符合预期，8/8 引用／版本检查有效；其中七条不同样本、一次重复，不能称“8 个独立样本”。
- `valid_paraphrase` 的 repair 仅为 `]`，评估器单列无文字建议的索引。现有产品不把 supported 的 repair 生成补救操作，故没有丢弃整份正确判断，也没有静默改写模型输出。
- `ticket_sufficient_strengthening` 开头把“持票者可以入场”称为必要条件，措辞含混；后句“入场者必须持票”和明确拒绝充分条件方向正确。记录为解释质量问题，不能因为 verdict 通过就忽略。
- 自我修正重复两次都接受最后立场，没有重复惩罚已撤回错误；findings 数量 1 与 3 不同，仅表示这两次结论一致。

生产模型及提示保持不变，本轮没有对这组有限样本调参后再花费重测。后续可按问题做单独受控改动。上述花费来自本机账本估算，不是供应商最终账单。
