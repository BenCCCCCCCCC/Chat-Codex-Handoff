# 免费示例之后，按选择进入自己的学习

## 发现与实现

在 [#50](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/50) 的 Windows 候选里，已有练习的学习者看完免费示例，点「开始自己的学习」会回到旧题。示例按钮和「学习首页」都链接 `/`，但 `/` 无新建草稿时会自动续学。不是学习数据丢失，而是首次体验、新建和续学共用了一个没有意图区分的入口。

| 入口 | 改后行为 |
| --- | --- |
| 示例「开始自己的学习」 | 打开首页并聚焦新主题标题；若已有材料草稿，直接恢复。仍可主动继续旧题。 |
| 示例「学习首页」 | 回到首页顶部，可选择继续上次或编辑自己的材料；不自动跳到旧题。 |
| 日常直接启动 `/` | 有新建草稿时保留首页；否则仍继续最近学习。 |

URL 只表示这一页的意图，打开主题后去掉该参数，不新增储存字段。学习记录、材料和草稿仍由现有本机逻辑管理；后端、模型、计费及留存不变。

## 定向验收

Windows Edge 158，隔离配置、免 Key、合成材料。通过 UI 保存第一份讲解、做普通练习，夹具只补入第一份合成诊断。由免费示例的真实按钮进入：改前直达旧题；改后可以留在新建页，也能显式继续同一道题、同一条旧回答。普通刷新仍续到旧题；从示例返回首页已保存的新材料草稿可见，开始新主题后旧题与旧答仍在。没有产品 API POST 或供应商请求。没有重跑其他用例。
