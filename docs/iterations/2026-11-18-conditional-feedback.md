# 材料条件接入反馈与离线质量基线

2026-11-18；基于产品 `1d0837d`，对应 MASTER 的材料适用条件主线及 Issue #3 离线范围。

讲解页可以明确选择本次相关的条件记录，最多 3 项。记录笔记本身不触发模型或重判。新反馈把条件快照、来源、讲解文字版本和每项判断绑定：显示“按条件可判”或“暂缓本项 · 不计作答错”，证据按需展开。暂缓项不带 supported／incorrect／missing，其他部分仍可分析。学习者采用的前提仍要核对材料，不能被当作已核实事实。

“另存新的处理”保留旧条件卡；切换本次条件后，旧反馈标为历史结果，再次确认才分析。恢复同一文字与同一组条件可直接查看已有结果。刷新、跨材料组合、前后对照及备份保留完整条件快照。条件绑定的反馈不自动进入尚未携带这些前提的旧补错练习；可以在原讲解上改答并再分析。旧题目的质疑／修订流程继续独立保存原题、回答及旧反馈。

实现使用可选 `attempt.judgementIssues` 与 `report.judgement`，不迁移数据库、不重写旧报告、不改到期方式。服务端沿已有单次诊断请求使用条件分组 schema，验证每个选定疑点恰好对应一项、引句确实来自当前来源、暂缓项没有判答 findings、判断索引不交叉；旧请求仍走原协议。最多 3 条内容 findings 的总限额不变。明确了来源前提缺失与学生漏讲已知条件的区别。

这不是自动语义复核器：问题是否相关、模型是否把本应暂缓的内容误归为无关项、是否正确解释引句，仍有语义误差。当前入口由学习者明确选择相关条件，工程结构校验不能证明模型诊断准确。没有增加独立复核调用。
