# 条件练习与再次作答证据

基于 MASTER `e9bf19a`、产品 `ce86094`，接续已确认的适用条件与题目核对流程。

## 交付

- 可判的条件反馈提供“按此条件练一题”。新题保存来源、讲解、文字版本、精确报告和条件快照；后续改笔记不改题。再次进入同一反馈回到已有题，明确换题才请求新情境。
- 条件出题和判答使用独立的结构化契约。请求只包含材料、固定条件及题面／本次回答；不发送旧回答或旧判语。材料引句须逐字存在，条件不支持或题面不足时返回暂缓，不记为学生答错。
- “再答一次”建立新记录，同文答案也有各自反馈。提交前保存回答与证据；未知结果只允许明确重试原回答，或另起一次并保留未知记录。已知未发送回滚，存储失败不自动再次付费请求。
- 每次回答固定记录此前答案与可用反馈 ID、当前／此前应用参考入口、学习者自报。反馈默认折叠，展开后的行为不会回写先前答案的证据；修订题继承已记录的参考入口。自报默认未知，不据此推断独立完成、迁移或掌握。
- 暂缓判答接入原有题目核对，学习者填写自己的核对说明后保留原题或另建修订题。修订沿用固定条件，旧题／旧回答／旧判语只读保留并排除为答错依据。返回原反馈展示准确条件、报告及原文字，保留当前工作。
- 刷新、搜索、材料组合归档及备份保存上述关联。含条件练习或待处理出题的导出使用 v3，旧应用会拒绝未知格式，避免忽略条件继续判答；本版继续读取 v1/v2。原报告已删除时练习快照仍可恢复。未迁移数据库、改变保留期或上传学习者原件。

## 验证

风险集中在同文重答、请求未知、前置保存失败、题目修订、历史引用及恢复。新增 5 个逻辑用例和 1 条 Edge 集成路径；其余复用既有练习／复核／备份测试。定向入口见 `docs/TESTING.md`。

本机定向 Node 24/24、Edge 1/1 已通过；390px 窄屏没有横向溢出，原题与修订题历史可往返。自审后补齐首次条件出题暂缓的恢复位置、修订前参考记录继承及复核说明由学习者填写；最终完整验证由 PR 的 Windows CI 执行，最终结果见 PR 和 MASTER。测试使用合成数据、隔离 profile 和 loopback provider，生产账本未变、真实 API 0 次。

首次本机完整 Node 验证发现无 AI 时的空练习数组提前变更，已修复为只读前置检查；首条浏览器自动化曾在保存尚未完成时填写禁用控件，修正等待条件后通过。后续不重复运行无关完整回归。

## 边界与下一步

条件是明确采用的前提，材料引用存在不证明其语义解释正确。结构化暂缓不能保证模型总能识别题面问题。应用只能观察入口展开，不能观察外部工具、记忆或是否实际阅读；旧练习不会补造参考记录。没有新增真实模型实验或已测学习收益。后续可按 Issue #3 冻结协议评审条件遵循、等义回答和合理质疑，实际调用需另行预算授权。
