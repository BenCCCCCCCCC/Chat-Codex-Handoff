# 让当前任务占据正文

承接 [#45](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/45) 的 V1 本地候选，以及 [MASTER 桌面减法方向](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/blob/be952d7/docs/master/reviews/2026-11-26-desktop-ui-direction.md)。保留苹果网页的留白与排版，把 ChatGPT Desktop 的层级用到学习任务上。

- 首页回访时先显示上次的具体问题或草稿，下面只写“新主题”。
- 主题内用细分隔区分材料和正文。输入、核对或交卷排在讨论前。当前重点并入正文上方；正在查看同一缺口时，只在该条反馈里显示一次问题和主动作。较少使用的导出、重开和删除收进“更多讲解操作”。
- 查看引文时，桌面从右侧展开原文，窄屏从底部展开，定位对应版本及页码。点击返回或按 Esc 后，键盘焦点回到原反馈。独立检验继续遮蔽材料，保留首次作答条件。
- 普通练习、独立首答和暂停判断的题目在每次打开时从现有作答证据定名。已见题刷新后仍标为普通练习。免费示例在重讲输入处标明自由文字不评分。
- 保存和发送的提示按操作出现。只有明确诊断时才提示发送材料及确认文字；已完成报告继续显示依据版本，过时和暂缓保留可见提示。

Windows Edge 以合成材料、模拟反馈走查了门禁的原句、局部重讲、18:05 新情境首答、恢复和质疑。按 Esc 关闭证据后核对焦点，先见普通题的另一条路径也保持原答题性质。本批保留既有来源定位场景，改用实际面板回读引文、页码与返回焦点。前一批已实测 320、390、768 和 1280 像素下的工作台与 320 像素下放大文本。CI 版本、结果及接续事项见[当前状态](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/blob/meta/master-state/docs/master/CURRENT_STATE.md)。
