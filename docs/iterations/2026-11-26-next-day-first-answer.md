## 唯一修复 · 跨主题见过同题

按审核队列的复现步骤，在 A、B 两个主题分别输入同一门禁规则，先漏讲截止时间，再局部重讲，然后从原问题进入独立检验。两题的题目、假设和三个选项完全相同，都是已实名但 18:05 才签到。每次双主题走查只有四次进程内模拟诊断，真实供应商调用和出站尝试均为 0。

| 检查 | 修复前 | 修复后 |
| --- | --- | --- |
| A 首次见题，答对并自报本次未查阅 | 记录独立通过 | 另确认“此前没见过这道题或它的答案”后可提交，原答保留 |
| B 已见同题，只勾本次未查阅 | 可提交，两主题都显示独立通过 | 独立提交保持禁用。选择“见过或不确定？转普通练习”可沿用所选答案继续，答对计为普通练习。重开仍为普通练习，A 的独立首答 ID 保留。[实页](v1-experience/seen-before-submit.png) |
| 历史记录 | v6 首答有无辅助自报，未询问此前是否见题 | 新首答单独保存见题自报；带该字段的 v6 往返后保留结论。旧形态的 v6 经导入逻辑读取后，原答案 ID 保留，显示“首答正确 · 此前是否见题未记录” |

自报只属于本次首答。跨主题没有建立见题索引。针对本次修改运行了双主题 Edge 走查及现有学习记录测试（2 项通过）；没有招募参与者或进行实际间隔 26 小时的学习效果测量。
