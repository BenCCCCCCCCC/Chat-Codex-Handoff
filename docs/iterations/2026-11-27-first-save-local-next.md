# 首次文字讲解：保存状态和下一步留在核对区

干净候选包的 390 px 实页发现：保存后焦点到「核对讲解文字」，页顶的本机保存和未发送提示却在屏幕外。就近显眼的是一个不可点的「配置 AI 后可分析」。

现把「已存本机、尚未发送」放在核对区。未配置 AI 时，从这里可「再讲一遍」，不显示禁用的诊断按钮。配置后，「确认并诊断」为主，旁边保留再讲；说明确认将发送材料选段和确认后的文字。复用原来藏在「更多讲解操作」里的按钮和编辑器，没有新卡片、存储字段或发送路径。保存失败、已尝试诊断或已有反馈时，不把本轮标成未发送。

390 px Windows Edge 验收一次：保存后提示与再讲均在当前视口，无横向溢出；按 Enter 可打开本机编辑器，0 POST。通过本机合成能力模拟启用 AI，看到发送提示但未自动请求；只有主动确认才产生一次 loopback 模拟诊断，请求含合成材料选段和确认文字，返回后不再说未发送。0 真实供应商请求、0 费用。未测真实模型、真人、麦克风或更广响应式范围。
