候选试图让建议改成同一来源内的小判断／预测／反例，避免把解释中的答案交给用户照抄。
实际效果不稳定：

| 案例 | 原配置 → 候选观察 |
|---|---|
| 无依据原因 | 改写“不确定” → 再问能否确定，仍重复已解释结论 |
| 必要条件 | 直接给出正确改写 → 假设“不满足其他升级要求”；引入了材料未提供的要求，题干也暗示答案 |
| 操作顺序 | 复述整套步骤 → 问称量下一步，答案仍已在解释中；两组均误称顺序“全部倒置／反过来” |
| 配方倍数 | 两组都问同一两份情境的乙用量；需要计算，但不是新情境，未观察到实质改善 |
| 抽样范围 | 复述样本结论 → 判断一个未抽中零件无裂纹是否与记录相容，这是有效的新判断 |
| 撤回错误 | 两组都接受修正后的正确立场，无修正建议 |
