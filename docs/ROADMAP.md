# 个人学习与作品展示路线

2026-10-20 用户确认定位：个人学习＋作品展示。此处是规划，实际状态见 `meta/master-state`。

| 顺序 | 问题 | 交付与判据 |
| --- | --- | --- |
| 1 | 访客不易理解、复现；诊断状态验证未完成 | README、公开源码、合成音频、回归与 CI；明确模拟／真实能力 |
| 2 | 相对通用工具的价值未证实 | 固定输入比较与评分表；两份历史结果均保留，记录一致性和失败 |
| 3 | 多源冲突可能造成无依据判错 | 受控案例和评测协议；明确来源裁决、错误／遗漏／优先级、弃权预期 |
| 4 | 作品缺少免费完整体验 | 独立且显著标注的模拟演示；无 key、不污染个人记录、不伪装 AI 实测 |
| 5 | 长期自用恢复能力不足 | 账本原子写入、故障恢复评估、导出恢复；先定数据保留策略 |

暂不优先：图谱大屏、整体掌握度分数、教师后台、无限多文件、停顿检测调参。由使用和评测证据驱动扩展。

常规改进按批次自审、提交和留痕。新增 API 支出、个人录音实验、保留期修改和大规模数据迁移先明确方案与预算。项目许可证待选，公开不替代许可证。
