# 简繁、定位与反馈：同输入配置比较

用户已于本轮明确批准本方案，最高 US$0.15。不继承上一批 US$0.10 的剩余额度。先完成离线检查，再执行一次固定比较。

## 可审阅的配置与样本

- 基线为 PR #15 的配置，已冻结到 `study-teachback-app/fixtures/quality-refinement-baseline.json`，来源提交 `330ab48adcdbfdad96a2f4e870efaf9b4805cfbd`。
- ASR：仍用 Whisper-1，两臂同一个 7.31 秒 Huihui 合成音频、语言 zh、词／段时间。基线不带 prompt；候选只加入“以下是普通话的简体中文转写。”。不把教材答案塞进提示，也不自动改写返回文字。两次 ASR。
- 内容：仍用 GPT-5.6-Luna。基线沿用旧提示／schema；候选对 supported 要求 repair=null，其余要求具体建议，并明确必要条件方向的表达格式。**比较整个提示＋输出合同配置，不能把变化单独归因于提示。**
- 六条固定内容，各跑两臂：既有等价改述、持票充分条件误推、自我修正、流畅但错误、遗漏条件；新增异领域规则“只有完成备份才能升级系统。”，讲解“只要完成备份就一定能升级系统。”，预期 unsupported_strengthening。共十二次语义调用，独立使用固定确认文字。
- 总计 **最多 14 次调用**；内容两臂交替先后，避免永远先跑同一配置。无自动重试、不追加样本；网络失败或不可用结构停止，已经返回的结果逐次保留。判断不符合预期则记录，不挑选较好结果。

## 评估与交付

- 分别记录严格 CER、实际字符差异、否定词／条件方向、有效／零长度词时间。词时间有效性不当作定位准确率；不修改原始零长度时间。
- 回听功能在离线真实浏览器验证：正常词直接定位，零长度词使用前后有效词组成的邻近范围（明确非独立词时间）；无法确定时退到整段。
- 内容记录预期 verdict、引用／版本、建议是否有内容、supported 是否无需建议，以及人工阅读条件解释是否具体、方向正确。两臂全部保留 requestId、reservationId、用量、配置与样本 hash。
- 单个声音、六条简单规则不代表自然口语、课程泛化或长期稳定率。若出现退化，优先保留已验证行为；本预算不用于循环调参。

## 预算

2026-10-20 核对 [Whisper-1](https://developers.openai.com/api/docs/models/whisper-1) $0.006/分钟，[GPT-5.6-Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna) 输入 $0.20/百万 token、输出 $1.20/百万 token。

按现有保守预留：两次 ASR 各按 3 分钟，$0.036；十二次内容各最多 24,000 输入／1,800 输出，输入按缓存写入 $0.25/百万预留，共 $0.09792。合计 **US$0.13392，硬上限 US$0.15**。实际短样本费用预计较低，但不因此扩大次数。不会充值、购买或自动重跑；与生产全局账本同时受限。

获批后唯一入口：`node study-teachback-app/quality-refinement-live.mjs --approved-budget-usd=0.15`。已有输出文件拒绝覆盖，旧实验报告保持原样。
