# 能否把修正带到下一题？

计划用 5–8 位正在用课件复习的学生做形成性走查。当前参与者 0 人。工程回放、预写示例和下面的参照答案均不计为参与者数据。

## 招募与同意

拟用邀请文字：“我们想观察学生怎样用材料复习一个概念。第一次约 25 分钟，24–48 小时后约 10 分钟。可以打字、跳题或中途结束。过程中的困难用于改进工具。参与与课程成绩无关。”

启动招募前确定招募渠道、研究负责人、记录存放地点、删除日期和任何费用，并取得相应授权。到场时分别确认参加、记录匿名观察、次日联系三项。录音和录屏默认关闭。使用提供的原创材料，参与者无需提交私人笔记或账号。联系信息与代号分开保管。退出时可要求删除未汇总记录。参与者可先查看拟保留的记录再确认。

## 两次任务

1. 记录代号、课程熟悉程度和常用复习方法。先问“最近一次把一道题做懂后，怎么检查自己是否会举一反三？”保留具体经历。
2. 分配两份相近长度的课程材料，交替工具和材料顺序。一半先用知而能讲，一半先用普通来源型助手。每个条件 8 分钟。两边获得相同版本的材料、目标和可用时间。初讲前均看不到示范答案。工具比较须提前确定可用服务和费用。
3. 给任务“读材料，解释结论在什么情况下成立。用提供的工具检查，按你认为合适的方式继续。”观察员不命名按钮。卡住时只问“你原本想做什么？”；如需救援，记录时间和动作。允许质疑题面。
4. 完成后请其指出一项反馈所依据的原句，解释是否同意，然后用自己的话再讲一次。记录首次定位、修正和遗漏。末尾问“哪一步你会在自己的复习中保留？哪一步会跳过？为什么？”
5. 24–48 小时后交叉使用预先冻结的平行题，改变对象、数值或适用前提。两组均先闭卷自由解释，再给选择或判语。记录额外参考自报。主持人保存首答后才显示答案。避免把原题复述当迁移。

自由解释每题三项各记 0／1。两位评审在不知道工具和分组的情况下独立判断是否说出概念、是否选对适用条件或合理暂缓、是否用材料中的关系解释新结论。保留不同意见和原始评分，随后达成的共识单列。选择正确但理由错误只能得对应的应用分。若研究题和示例出现重复，标记已见并更换未见版本。

## 观察记录与分母

每条观察记代号、材料/工具与顺序、目标、开始和结束、首次确认、查到哪句、第一次重讲、是否求助、首次作答、参考自报及退出原因。可复述界面现象，少量必要引语先征得许可。时间从任务开始算，未完成保留截止点。

| 指标 | 分子和分母 |
| --- | --- |
| 首次讲解完成率 | 无主持人救援提交首次讲解的人次 / 已开始该学习任务的人次。另列救援后完成和中途退出 |
| 定位与修正耗时 | 从反馈首次显示到找到对应原句，再到首次相关修正，分别记录时长、完成数和未完成数 |
| 延迟回访率 | 按时返回的人数 / 同意回访并完成首次任务的人数 |
| 无辅助迁移 | 同时满足三个评分点且自报无帮助的未见题首答数 / 已实际收到的无帮助未见题首答数。同步列出应回访、缺席、已见、参考及缺理由的人数 |
| 诊断质量 | 分别计无来源依据的判错 / 全部知识指控，应暂缓却判错 / 应暂缓项，引用与目标不符 / 已给引用。保留逐案复核理由 |
