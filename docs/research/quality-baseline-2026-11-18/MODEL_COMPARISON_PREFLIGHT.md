## 冻结的候选配置

[run-manifest.json](run-manifest.json) 显式列出 24 个固定槽：6 例、两种配置、各两次。每轮按案号排序，每例反向平衡配置：第一轮 Luna→Sol，第二轮 Sol→Luna。同案同输入、instructions、strict schema；无工具、音频或额外材料。拟采用 Standard 响应、短上下文、文本、`store:false`、`background:false`、不流式和 30 分钟缓存写入档。每槽从派发到完整响应（含响应体）均以 **60 秒**为上限，串行，零自动重试。60 秒沿用产品等待边界。Sol 的 6,000 是拟评估的可部署配置，留给推理与可见 JSON 的**总量**，不声称总能完成或足够测出模型上限。

- 六例×两种配置实际编码体最大 **13,154 字节**。每槽 UTF-8 编码体上限 **14,000 字节**，按“每字节最多一个文本 token，加 2,048 预留给供应商包装”保守做本地预算，即 **16,048 输入 token**。这是本地上界假设，不是提供方公布的计费上限：超字节在派发前拦截；目标项目不能证实限制、适用费率或缓存 TTL，不能开跑。实际 usage 超边界或账单归因不明即停止，不把超出的费用当零。没有 Fast、批处理、长上下文附加或缓存命中节省假设。
- 12 槽 × (16,048 × 0.25 + 1,800 × 1.20) ÷ 1,000,000 = **US$0.074064**；12 槽 × (16,048 × 2.50 + 6,000 × 10.00) ÷ 1,000,000 = **US$1.201440**。24 槽的合计预留上界 **US$1.275504**，全按比普通输入更高的 30 分钟缓存写入费率计。仅在上述条件成立时适用，未含税、充值、汇率或其他服务，非已产生账单。脚本预留用整数十亿分之一美元，另以独立展开式交叉核对。
- 每槽先预留、再派发。usage 可信且在边界内才结算；未结算保留全额预留。本 mock 结算仍用缓存写上界，不模拟供应商实价。若权限／档位／strict schema／费率不兼容，超时或不完整响应未获可靠 usage，或下一槽超预算，**立即停止**，保留失败原槽和余下未发送槽。即使拿到 usage 但 JSON 不合格，也应记录费用、不可用结果和原因；不更换配置或补跑。本脚本只验一组成功对与一条未知 usage 的停止，不覆盖其他所有真实故障。将来若有授权，应另行提供隔离、耐崩溃的预留账本和可审计断路实现，不可拿这里的内存 mock 直接改成真实发送器。

## 如何本地复验

从本研究分支仓库根目录运行，Node 24.21 或支持同步模块守卫的同系列版本：

```powershell
$r = (Resolve-Path 'docs/research/quality-baseline-2026-11-18').Path
$app = (Resolve-Path 'study-teachback-app').Path
$out = Join-Path $env:TEMP ('diag-preflight-' + [guid]::NewGuid().ToString('N').Substring(0,12))
New-Item -ItemType Directory -Path $out | Out-Null
node --permission "--allow-fs-read=$r" "--allow-fs-read=$app" "--allow-fs-read=$out" "--allow-fs-write=$out" (Join-Path $r 'model-comparison-preflight.mjs') --out $out
```

预检要求 Node 文件权限模式，不允许子进程、worker 或原生插件；加载守卫只放行四个纯本地模块，浏览器式通信、内建模块旁路和网络模块不可用。五个拒绝探针在进程内阻断，不做 DNS、TCP、HTTP、回环访问或加载产品 provider。**这是程序内能力隔离，不是系统防火墙或对任意第三方代码的网络隔离声明。** 不载入任何 Key、认证代码或生产账本，不用真实网络等待 60 秒。

实测 `PASS_OFFLINE_ONLY`（Windows / Node 24.21.0）：manifest LF SHA256 `832bd32efebd04b1d8a2869c58a7cfd9421cfcfd1eba165d3bb437a67692699b`；旧协议、样本、评审表指纹和 **6/6** 输入、instructions、schema 指纹与原排练一致；固定槽 **24**，实际只派发纯函数 mock **3**（同案两份及下一槽未知 usage），5 个网络能力探针被挡。E03 的 `US$0.006172` 模拟预留不释放；两份已结算模拟费用上界与该预留合计 `US$0.010480`，余下 21 槽未发送且无补跑。旧 12,000 字节草案在 mock 前被正确拦截：四材料案编码为 13,154 字节；仅重新锁定字节门槛，没有改已有输入。真实供应商请求与实际支出均 **0**，兼容性、速度和质量未测。
