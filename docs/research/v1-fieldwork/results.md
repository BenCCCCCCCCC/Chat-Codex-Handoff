## 首次查证摩擦：逐人配对

本轮唯一主指标为“为同一原句的额外查找次数”。两边均有针对该材料既定缺口的可操作反馈、能独立定位到原句、在时限内提交针对缺口的改讲，且计数完整，才算可比较。无反馈、未找到、主持人救援、超时和退出均保留在全部已分配任务的统计中，注明出现在哪个工具和次序，不计为改善。按各自材料的既有评分锚点判断修正质量。

| 代号 | 知而能讲：材料／次序 | 普通助手：材料／次序 | 额外次数：知而能讲／普通助手 | 补齐关键条件：知而能讲／普通助手 | 可比较／原因 | 结论 |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

知而能讲的额外次数更少、补齐关键条件且质量不低于对照，记改善；次数和质量均相同，记持平。修正质量下降，或次数上升且质量没变好，记变差。其余混合结果单列，不计改善。两边一次找到且质量相同是持平；普通助手查两次、知而能讲查一次且双方均补齐是改善；查得更少却漏了对照已补齐的关键条件是变差。

原门槛：至少 4 个可比较配对，且至少 4/6 招募者在预定指标上改善、修正质量不降。未达时按实际情况记证据不足或方向混合，不换指标补算。报告可比较数、各结果人数与未观察原因；检查材料、工具次序和掉队是否集中。单个人在两种工具下用不同材料，结果用于形成性取舍。
