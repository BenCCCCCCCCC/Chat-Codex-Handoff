# 形成性走查执行包

研究问题是，学生能否自己从一条反馈找回材料，修正解释，并在次日把这个条件用到另一道题。计划 6 名学生，每人试用两种工具。当前参与者 0 人。首次和回访的用时、交叉顺序、独立评分沿用[研究协议](../v1-formative-study.md)。

## 主持流程

打印或在受限本机复制[现场记录页](session.md)；两次任务共用同一个参与者代号。两个工具都仅展示当前题和所需材料。给学习者看的窗口与主持记录、答案分开。

| 首次会面 | 主持人 |
| --- | --- |
| 0–4 分钟 | 说明退出、酬谢和记录范围，逐项确认同意。问最近一次检验自己是否弄懂课件的经历，以及是否接触过公开示例或题库。 |
| 4–12、12–20 分钟 | 按协议顺序依次开启两个工具。逐字说“读这段材料，用自己的话解释结论在什么情况下成立。用面前的工具检查，再按你认为合适的方式继续。”开始计时，记下自然发生的动作。 |
| 停住时 | 先问“你原本想做什么？”并记时。需要指定操作时逐字记录；给出按钮或路径提示后，此后的完成计为救援后完成。使用者可以质疑和退出。 |
| 20–25 分钟 | 对自然完成和未完成者用同样的追问：“反馈根据哪句材料？现在会怎么讲？”这些追问后的动作用单独栏记录。问哪一步会在真实复习里保留、为什么。确认回访安排。 |
| 次日 0–2 分钟 | 确认与首次任务间隔及是否额外复习。以首次材料的逆序出题。打开首题前关闭材料、对话和旧作答。 |
| 次日 2–10 分钟 | 每题最多 4 分钟。每题先问是否见过，要求自由解释并给理由。锁定首答和参考自报后才揭示下一步。评分员各自先判，封存两份原评后再讨论分歧。 |

## 回访题如何保管和替换

已在本机研究包冻结两份首次材料、每领域一份主回访题和一份备用题，以及独立的评分锚点。题目考查条件概率的取样群体和缓存复用的适用条件。主持人仅把当前材料或题面给学习者。评分锚点及版本指纹见[清单](forms.md)。

- 先登记是否看过公开课程、研究协议或具体题目。默认使用未公开的主版本。见过具体主回访题，在作答前换同领域备用题，同时记主版本和暴露原因。
- 交过首答才识别出见题，或备用题也见过，保留当次记录并退出该题的独立分析。答错、沉默、查阅或超时均不得触发换题。
- 在另一台主机执行时，从研究负责人取得原包或在本机重新命题并登记新指纹。新题保留同一目标、相近篇幅和难度。跨版本单列；上线前由另一位评审检查题意和三个评分点。
- 结项用[匿名结果页](results.md)汇总两工具的分母、救援、参考和失访，再决定下一轮只修哪处摩擦。
