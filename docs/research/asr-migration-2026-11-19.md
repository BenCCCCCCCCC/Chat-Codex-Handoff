## 官方依据与实现

当天重新核对 [弃用公告](https://developers.openai.com/api/docs/deprecations)：`whisper-1` 的关闭日为 2027-02-26。[文件转写指南](https://developers.openai.com/api/docs/guides/speech-to-text) 推荐完成文件使用 `gpt-transcribe`，支持 `languages[]`、`keywords[]` 和上下文 `prompt`；不同时传旧 `language`。词句时间参数仍只属于 Whisper。候选以 JSON `text` 返回作为最低能力，不假设存在 `segments`／`words`。

`asr-contract.mjs` 将请求构造、返回归一化、能力和费率分开。现有 provider 接入同一合同，但生产常量仍锁定 Whisper，HTTP 请求不能指定模型。候选准备只有离线入口。

无时间的文字按编辑上限分块，每块回听实际整段录音，保存 `timing.level=recording` 和本机音频时长来源。它不是推测出来的词句区间。反馈、历史回听、备份保留这一限制；内容判断仍只发送文字。声学事件可独立保留，但不因整段时间重叠就和某句错误建立关联；旧 delivery 接口拒绝这种关联。

每次 ASR 预留保存模型及当时费率。旧 Whisper 账本继续按原费率结算，失败预留保持风险占用；不把候选价格套到历史记录。官方模型页列 [GPT-Transcribe US$0.0045/分钟](https://developers.openai.com/api/docs/models/gpt-transcribe)、[Whisper US$0.006/分钟](https://developers.openai.com/api/docs/models/whisper-1)。按本机时长向上取整秒形成保守估算，非账单证明。

## 下一步比较设计（未执行）

只使用明确获准的合成／自愿低风险录音，不读取私人历史原件。准备以下 8 条短音频，每条不超过 45 秒；每条两模型各一次，共最多 16 次，不自动重试。音频尚未制作／冻结，因此这些是脚本设计，不是已经取得的质量样本。

| 样本 | 合成脚本要点 | 首要判据 |
|---|---|---|
| 否定条件 | 并不是队列满了才移动头指针；出队后才移动 | 不丢“不是／才” |
| 数字边界 | 长度八，预留一个空位，只能放七个；长度十则放九个 | 数字及条件配对 |
| 中文术语 | 循环队列、顺序队列、头指针、尾指针 | 术语不互换 |
| 中英混合 | 用 count 记录个数，front 和 rear 相等不一定为空 | 提示可改善拼写，不补出未说词 |
| 自我修正 | 可以放八个……不对，这里预留空位，应该七个 | 保留修正过程与最终说法 |
| 等义表达 | 水分子从液面进入空气，这就是蒸发 | 文字忠实，不改成教材答案 |
| 停顿和弱音 | 在不失真的前提下停顿后继续说明上述条件 | 不能把安静区间补成词句 |
| 中断片段 | 这里只讲了预留空位，另一种实现还没…… | 保留片段，不补完未说的结论 |

由人先独立标注逐字稿与关键否定／数字／条件，然后盲看两组输出。记录关键语义改变、中文字符差异、术语、无中生有、失败率和实际回听可用性；合同测试通过率不能当中文准确率。原输出、失败和人工裁决都保留，不挑好结果。新模型若改变关键条件或添加未说内容，先分析原因，不直接生产切换。

时长上限 6 分钟／模型，公布费率估算合计不超过 US$0.063；按应用每次 3 分钟的预留上限，最高风险占用 US$0.252。建议申请总上限 US$0.30、16 次、禁止自动重试。开始前重新核对价格、账户可用性和录音授权；若真实合同不符，停止后报告。质量比较与生产切换须分别记录结论，不能因预算批准就自动切换。
