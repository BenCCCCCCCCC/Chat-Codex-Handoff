# 知而能讲 V1.0｜PRD 补充：竞品分析与迭代机会

2026-11-27 · 产品基线 [ef325a7](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/commit/ef325a7385a198b0a68116fd5d79472314bce97d)

## 1. 调研目的与结论

早期 [10 月 20 日学习产品与机制调研](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/blob/ef325a7385a198b0a68116fd5d79472314bce97d/docs/research/2026-10-20-landscape.md) 已分析同类产品与设计借鉴；[HANDOFF](../HANDOFF.md) 进一步识别 ChatGPT、Gemini 的竞争威胁。此前尚缺少系统的竞争分层、用户选择理由、优势证据、机会优先级与比较方案。本篇补齐这些 PRD 要素，保留原始调研。

目标用户仍是带着课件或笔记、为考试或自主学习复习复杂概念的大学生及自主学习者。本轮聚焦国际通用学习工具与费曼式直接竞品；尚未做国内渠道、地区市场规模、付费意愿或代表性用户访谈，不能据此推导商业规模。所有竞品信息来自截至 2026-11-27 查阅的公开官方功能说明与公开入口，未登录实测、上传材料、购买服务或测量学习效果；“未核实”不代表没有能力。市场压力为定性产品经理判断，不是市场份额或性能排名。

**结论：** 费曼教回、AI 诊断、来源引用、复习计划、进度记录均已进入竞争市场。机会是让学习者以较低操作成本完成一个可核对、可修正、可再次独立验证的具体理解缺口，并在下一次学习中找到同一个问题。现有工程结构支持这项定位，但真实反馈质量、任意课件覆盖及对照学习成效仍待验证。

## 2. 竞争格局与选择理由

| --- | --- | --- | --- |

| 自适应学习： [Gemini Study Notebooks](https://blog.google/innovation-and-ai/products/gemini-app/gemini-study-notebooks/)、[Gemini Live 学习场景](https://blog.google/products-and-platforms/products/education/gemini-finals-study-tips/) | 诊断测验、知识缺口、自适应短课、进度与优先推荐；Live 可口述解释并检查逻辑缺口 | 对诊断→补学→复习的全面竞争；不能以语音或进度跟踪宣称独有。参考面向用户目标的下一步设计 | 高 |
| 费曼式垂直产品：[Feynman AI（feynmanai.net）](https://feynmanai.net/features) | 自建主题、语音/文字解释、多维分析、针对性修正、历次成绩趋势 | 直接重合教回循环，参考轻量首讲和反馈可行动性。对照具体知识指控是否有依据、修正能否迁移，而非比较评分维度数量 | 高 |
| 费曼式垂直产品：[Meomy teach-back](https://meomy.alicsystems.com/feynman-technique-study-app/)、[产品介绍](https://meomy.alicsystems.com/) | 用自有材料与解释生成反馈，查漏补缺、重讲；免费网页入口，移动产品提供学习集与复习能力，公开说明本机保存方式 | 更贴近“材料+解释→反馈”；本机存储和来源比较也非独有。参考低门槛首个反馈、导出和继续学习，不照搬免费额度或数据政策 | 高 |
| 来源型学习：[Gemini Notebook（NotebookLM）](https://support.google.com/gemininotebook/answer/16958963?hl=en) | 来源驱动的闪卡、测验、解释及进度恢复；与 Gemini 学习空间相连 | 用户需要读多份资料、快速生成练习时有强替代性；我们的有限选段与本机出题范围是明显劣势。不要竞争完整资料库或内容生产 | 高 |
| 知识管理与复习：[RemNote](https://www.remnote.com/feature/ai-flashcards)、[AI Tutor](https://help.remnote.com/en/articles/10103884-ai-tutor-chat) | 笔记/PDF、可点击引用、AI 辅导、语音及文字评判、间隔复习与测验 | 已同时覆盖来源、解释、复习；参考材料旁辅助交互、可编辑学习产物及回访队列。聚焦具体理解证据，不重造知识管理系统 | 中高 |
| 考试复习：[Quizlet Learn](https://quizlet.com/features/learn)、[使用帮助](https://help.quizlet.com/hc/en-us/articles/360030986971-Studying-with-Learn) | 闪卡转自适应题目、多题型、学习计划及跨设备进度，部分高级功能需订阅 | 快速考试刷题和持续复习的替代选择；借鉴短而明确的任务，不追求题量和题库规模 | 中高 |
| 长期记忆：[Anki](https://faqs.ankiweb.net/what-spaced-repetition-algorithm) | SM-2 / FSRS 调度、主动回忆与个体复习安排 | 低成本长期记忆管理的替代选择。针对复杂条件与推理的诊断场景不同；先验证回访需求，再考虑轻量复习提醒而非完整调度算法 | 中 |
| 非软件替代：自己复述、同学互讲、课后问老师、手工错题本 | 低额外工具成本；教师或同伴有课程语境，纸本可长期保留 | 用户未必需要 AI。比较查漏补缺的时间、可信度、可回访性和实际效果，避免只比较应用功能 | 重要基线 |

可访问方式及成本不是等价的价格比较：ChatGPT 学习模式随现有计划规则；Meomy 公布有限免费网页入口及移动增值功能；Quizlet 有有限免费体验与订阅；其他额度和价格按地区/账户变化，本轮不记录无法核实的数字。知而能讲当前免费预写示例与免 Key 本机保存不产生供应商请求；自有材料的真实诊断需自行配置 API Key 并承担用量费用，Windows 启动及安装也是额外门槛。尚无成本优势或获客优势的实测证据。

## 3. 产品差异化与证据

| 用户价值 | 当前设计与证据 | 与竞品比较的优势假设 | 仍需证明 |
| --- | --- | --- | --- |
| 更容易看到自己哪一点没懂 | 首讲显式入口、具体错误/遗漏、原文与原话；[#46](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/46)、[#47](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/47)、[#54](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/54) | 相比自由对话，默认任务流程减少提示词编排；相比通用测验，可围绕用户的真实解释给出具体反馈 | 首次有效诊断率、耗时、诊断严重错判及实际价值感知 |
| 反馈可查证、可追责 | 材料版本、学习目标、初讲文字版本、原反馈项精确关联；材料查证可返回原反馈；[#41](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/41)、[#53](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/53)、[#55](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/55) | 以原始表达、原文与适用条件共同构成可回看的纠错依据，而不仅是一个模型分数；现有架构证明可追溯性，不证明别家没有类似能力 | 引用与判断正确率；用户是否能自主查证、修正及处理冲突 |
| 修正后验证能否举一反三 | 同一缺口局部重讲、有限规则独立首答、已见题及参考自报、题目质疑；[#44](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/44)、[#49](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/49)、[#52](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/52) | 区分讲得出来、看过答案后答对、在新情境独立应用；以过程证据而非笼统掌握分数呈现进步 | 多段材料的安全针对性检验覆盖、未见自由解释和 24–48 小时延迟迁移。当前 [本机规则](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/blob/ef325a7385a198b0a68116fd5d79472314bce97d/study-teachback-app/bounded-understanding.mjs) 非通用开放题引擎 |
| 让下一次学习接续同一问题 | 精确恢复待检验缺口、旧答案与依据、单主动作；[#57](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/57)、[#59](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/59)、[#60](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/pull/60) | 理解档案不只记录历史，直接指向下一项学习行动，可能降低再次学习的上下文恢复成本 | 自愿回访、续学耗时和同一缺口续学率；七天到期限制长期档案价值 |
| 数据与成本可理解 | 本机选段/草稿/档案、明确发送及账本，离线示例和备份；[README](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/blob/ef325a7385a198b0a68116fd5d79472314bce97d/README.md) | 可控的本机工作流和知情选择；不是完全离线 AI 或绝对隐私，也不能断言比其他产品更安全 | 配置成本、真实调用费用、用户信任与保存/导出需求 |

**定位句：** 面向需要检验复杂概念理解的自主学习者，用材料和自己的讲解发现具体缺口，查证、修正并在新情境中独立验证，留下可继续的学习证据。

竞争壁垒尚未形成。稳定的证据链是已实现的产品架构优势候选；能否成为用户偏好取决于反馈准确性、真实闭环覆盖、效率和学习效果。无需通过增加大而全功能来制造差异。

## 5. 竞争验证与成功指标

复用 [形成性研究执行包](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/blob/ef325a7385a198b0a68116fd5d79472314bce97d/docs/research/v1-fieldwork/README.md)，不另行招募或创建评测框架。以既有普通 ChatGPT 对照为基线，设计面向同一任务的强提示：同材料、目标、时间、首次解释、核对来源、修正及独立回答的要求尽量一致；另记录 Study Mode/专业竞品后续可用性验证机会，不能在已冻结的六人研究中静默改变分组或事后挑有利对手。新增工具涉及数据或费用时先授权，若将来获准比较，预先登记模型/版本/地区、设置、任务、评分和资源限制。Feynman AI 与 Meomy 是优先的直接体验对照候选，Gemini Study Notebooks 是成熟闭环对照候选。

主要评价分为三层：
- 操作效率：从导入到首次有效诊断的完成率和耗时、主持救援、查证返回和中断恢复；记录配置/无题等退出分母。
- 诊断价值：真实错误与遗漏是否被正确定位，依据是否充分，用户能否独立修正；严重误判单列。采用已有质量协议。
- 学习与留存：首次独立回答、24–48 小时未见自由解释（概念/应用/理由）、D1 自愿续学及同一缺口续学；D7 明确观测窗口，现有七天到期导致无法观测时报告不可测。约定回访、重复答已见题、保存重讲或仅打开不算学习价值。

北极星沿用 MASTER：每位活跃学习者在允许的留存期内，经有效独立检验实际解决的唯一理解缺口数。记录缺访、无题、未诊断等漏斗损失，不用模拟/CI/竞品营销效果数字作为用户结论。6 人形成性研究只帮助定位问题，不用于市场或统计显著性推断。
