# 待检验回访 · 隔离 Windows Edge 验收

对应 [PR #57 原样实现 d17d1e6](https://github.com/BenCCCCCCCCC/Chat-Codex-Handoff/commit/d17d1e6543f41a6634306cc11e28a1eacd07be4c)，基线 bd6b569。独立 Windows Edge 验收，1280 × 1000，免 Key，全部为合成材料、合成反馈与本机记录。

- 先保存旧规则题的「9 克」正确首答，再从多段材料对应反馈进入待检验并保存局部重讲。重讲保留原讲解、来源和完整反馈引用。
- 从待检验查看旧题并刷新，原首答与待检验状态均保留。从理解档案中恰好匹配的反馈项点击「继续待检验」，回到同一缺口。
- 回到待检验时新增题、作答、评分、独立通过均为 0；POST 与供应商请求也为 0。
