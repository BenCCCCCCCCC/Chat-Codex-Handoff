## 产品要赢在哪里
复习者能复述定义，却容易漏条件、混淆比较基准，或在换情境后用错规则。第一批人是拿着短课程材料、有明确复习目标的中文成年自学者。承诺是「讲一遍，找到漏点，看原文，改讲，再换题」；不是生成总结、刷卡片或认证掌握。现有依据是产品观察、合成两领域走查及 [检索练习原研究](https://pubmed.ncbi.nlm.nih.gov/21252317/)，不能证明本产品需求或效果。

| 01 机会 | 先看近期确实做过这种复习的人，不问“你喜欢 AI 吗”。追问最后一次没讲清的概念、用的替代品、是否实际回去查证。 | 有具体重复情境及替代成本，才保留目标场景；未访谈，不称已验证。 |
| 02 市场与用户 | [ChatGPT Study Mode](https://openai.com/index/chatgpt-study-mode/) 有引导和理解检查；[NotebookLM](https://blog.google/innovation-and-ai/models-and-research/google-labs/notebooklm-student-features/) 有引文、测验和答案说明；[RemNote](https://help.remnote.com/en/articles/8663109-flashcard-basics) 有笔记内练习。现有六人两领域协议用于形成性观察。 | 和同材料、同可用时长的普通助手对照，保留 24–48h 未见自由解释与盲评，报告分母和排除；六人不作统计推广。若多数已用普通助手轻松完成同任务，收窄或停止做通用产品。 |

| 04 规划 | P0 从材料到下次继续；P1 工作台和 Windows 首启、定向 AI 检验；后置账号、云同步、向量库、代理、多端。 | 有影响证据才加面板或新流程；来源、档案与历史保持可访问。 |
| 05 体验 | Apple 用于首体验的节奏与层级，ChatGPT Desktop 用于稳定导航和就近输入，NotebookLM 用于原文定位与返回；RemNote 借鉴待复习提示，不照搬卡片或品牌。 | 桌面 1280px 收起材料后正文不挤窄格、展开才分栏；390px 无横向溢出，原文返回保留原任务，有键盘路径。首屏只保留现在要做的动作与必要证据。评审看实际对比，不以好看代替真人可用性。 |

## AI：哪些靠模型，哪些靠程序
[现用模型、对比试验与成本口径](reviews/2026-11-26-model-comparison-decision.md)
- **能力定义**：模型提议概念、基于材料标出疑似缺口和解释原因，语音仅作输入辅助。程序负责材料限额、引用定位和版本、状态机、档案、首答资格、保留期、费用预算。结论不以模型自报置信度代替。离线示例和规则题明确标注，覆盖不到就不冒充真实诊断。
- **模型选型**：当前生产诊断/转写常量不换；盘点实际版本及请求路径。比较当前文字模型、一个轻量、一个高推理档，使用同题同输入、隐藏模型标识，分别看严重误判、合格诊断率、p50/p95延迟和每个可用诊断的成本。归档转写 #42 两模型均发生关键数字误听，新转写也未提供词句时间；迁移先核对中文关键字和整段回听降级。没有新 API 结果，不宣布赢家。工程规划/审查用能力最强可用档，不等于学生每次请求用最贵模型。
- **工作流**：材料选段与目标 → 用户确认讲解文字 → 服务按 ID 拼装最小上下文 → 固定提示词及结构化输出 → 程序核验来源、引文和字段 → 给一个可核对的缺口 → 重讲/独立题。原文和用户输入都是数据，不接受其中的指令；暂不加自主 Agent、联网检索和向量库。评测证明截段漏条件或多材料召回不足后，才比较本地词法检索与现有直接上下文。
- **数据**：只持久化选段、目标、稿件、来源与证据等现有字段；原件留本机、7 天保留、12 份逻辑材料、单份/合计发送范围沿用 5,000 字规则。真实诊断发送范围在确认前可见，统计用聚合或显式脱敏导出，不默认联网。供应商保留政策另核，不把本机删除等同云端删除。
- **评测**：复用 4 份合成源、14 个冻结案例与现场协议。增加高影响反例时先冻结预期：否定条件、比例分母、缺少依据、多源冲突、已有正确答案、无合法引用、超时和断网；按“虚构依据/颠倒关键条件/错误判已学会”与一般文案问题分开。离线基线用于验证校验器和状态，不能用于声称真实模型准确率。小样本用原始 n/N，不用百分比遮住样本量；黄金结果独立复核。
- **异常**：无依据→“先核对这条”，矛盾→展示两个来源及条件，不强判；超时/无效结构→留原稿、给主动重试或改文字，不自动隐性重复付费；转写数字及否定错→用户确认；题目质疑→暂不计入证据，保留原记录。
- **成本**：记录允许的 usage 与可用诊断数，不记录材料到日志。单次成本=输入/缓存/输出 Token × 对应费率 + 音频时长项，未知计费标记未知；每位用户成本按实际诊断和转写次数测。默认只调用一次；超限先阻断并明确原因。复用已有账本、硬预算和费用收据，不因切模型重计历史。
 
## 第六轮修订：怎样才算过门槛
依据 [原 Chat 第六轮独立审核](reviews/2026-11-26-v1-review-queue.md#2026-11-26--八阶段--ai-放行门槛独立评审第六轮)。这是产品决策规则，不是 #49 的工程缺陷或已完成的实验。

**需求与真实价值。** 先记录六位目标学习者在近 30 天的近期事件及实际代价，再展示产品。至少 4/6 独立提供可核对的重复情景与替代工具摩擦，才把该场景保留为下一轮重点；否则缩小目标或暂停。只保留一个强对照，提供同材料、时限和正常学习功能，不把通用助手故意削弱；NotebookLM 可做独立合成功能走查，不把三工具混成六人实验。价值侧预先指定“从读到依据到自主完成同一缺口的修正，是否少一次救援、反复找原句或重述需求”，至少 4 个可比较配对，且至少 4/6 招募者出现所选的摩擦改善而修正质量未下降，才扩下一轮验证；证据不足或方向混合标未定。24–48h 未见自由解释独立盲评另列结果；不能因为体验更顺就宣称学习效果更好。全链路按分配任务报告分母和掉队，再附合格未见无辅助题的条件性比例。安排回访与自然回访分开，不把到场当留存。

**AI 放行。** 合格诊断须同时做到：依据存在且适用，已表达/缺口/暂缓判定正确，有一个有用的下一动作，或证据确实无缺口而不硬编。全部分配槽位入分母，截住的严重原始错误另列为不可用，无法判断账单的保留未知。高影响冻结用例中，任何一个用户可见的严重错误（一项重要条件/数字颠倒、虚构关键依据、严重错绑或虚报独立通过）否决本次切换或扩大灰度；零观察不等于零风险。候选合格数不低于基线、无新增关键失败，再比较延迟与可用结果的费用。若只测工程，不标模型质量通过。

**本机放行和回滚。** 三个状态单列：本地候选可安装／AI 配置可切换／对外版本可放行。一次隔离演练即可：冻结新旧包 SHA 和旧 profile → 用合成数据在新版新增来源版本、讲解/诊断、首答与草稿 → 暂停新使用/调用，备份新增后的完整 profile → 上一包只用兼容数据或隔离旧快照 → 恢复新版回查新旧证据与账本，不损坏本机正式记录。旧包无法识别新增语义则标“不可原地降级”；导入新副本会另起保留期，不能冒充原位回滚。严重计费、隐私、串题、记录丢失或严重误判即暂停受影响路径，不靠隐性重试或改权限绕过；问题修后定向复验。待研究/发布授权时不阻塞安全的本地工程。

## 接力顺序
1. Codex：先以当前远端为准接下一张桌面练习任务，复现与修复齐备后给 PR、实页前后图、窄屏、测试；再做本机候选安装/恢复和 AI 质量离线补差。每轮单一代码负责人，不重复上一轮。
2. 原 Chat：按 [审核队列](reviews/2026-11-26-v1-review-queue.md) 对比市面产品，评审新证据，只写 Must Fix、Next、需用户决策。不得把分派任务当已完成。
3. 隔离本机内的验收、演练和合成评测继续做；如确需真人外联、付费 API、公开部署或改变数据/ASR，先把目标、影响、预算与回退压成一次明确决定。未完成这些不能宣称验证了实际学习效果。
